# Закрывающий тег

Одностраничный сайт-дневник о пути в вёрстке: восемь карточек по этапам курса, у каждой лейбл с состоянием, лайк и немного личных воспоминаний. Проектная работа Яндекс Практикума.

- Репозиторий: https://github.com/AGSole102/zakrivayuschiy-teg-f
- Сайт на GitHub Pages: https://agsole102.github.io/zakrivayuschiy-teg-f/

## Что внутри

- Резиновая вёрстка от 320px, брейкпоинт 375px, размеры через `clamp()`.
- Вариативный шрифт Inter и пиксельный Press Start 2P.
- Фиксированный фон-сетка из нескольких градиентов.
- Лейблы на картинках с `mix-blend-mode` и обводкой текста, фоллбэк через `text-shadow`.
- CSS-фильтры на изображениях карточек.
- Кнопки с заливкой по наведению и инверсией текста через `mix-blend-mode: difference`.
- Инлайновое SVG-сердце с анимацией наведения, зажатия и лайка на `transition` и `@keyframes`.
- Модальное окно на `<dialog>` со стилизованным `::backdrop`, иконка дискеты подключена через `<symbol>` и `<use>`.

## Структура

```
index.html
fonts/     шрифты и @font-face
styles/    переменные, глобальные стили, основные стили, анимации
scripts/   лайки и открытие модального окна
images/    фото карточек и фавиконки
svg/       спрайт с иконкой дискеты
```

## Запуск

Откройте `index.html` через любой локальный сервер, например `npx serve`. Иконка дискеты подключается из внешнего SVG-файла и не отобразится при открытии страницы напрямую как файла.
